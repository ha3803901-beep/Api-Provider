Step-by-step setup

  1. Create a free account at the provider dashboard — no credit card is required for the free tier.
  2. Open the API keys page, click Create new key and copy the value.
  3. Store the key as an environment variable named FREEAI_API_KEY. Never commit it to Git.
  4. Point your OpenAI SDK at the Base URL above — every provider in this directory speaks the OpenAI Chat Completions format.
  5. Run one of the snippets below to send your first request.
